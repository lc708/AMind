## Anthropic Fellows Program: The J++ Lens

Kola Ayonrinde, Jack Lindsey

In our recent paper, we introduced the Jacobian lens (J-lens), a technique for reading out the concepts that a model represents at its intermediate layers. In an Anthropic Fellows Program project led by Kola Ayonrinde, we developed an improved version of the J-lens that we call the J++ lens.

The J-lens is computed by averaging Jacobians over a large number of source token positions, all weighted equally. In practice, some of these positions contribute very noisy gradients that corrupt the average. The main change in the J++ lens is to cluster the activations at each layer and fit a separate Jacobian to each cluster. These cluster-specific Jacobians are then combined using learned weights, which in practice mostly serve to discard the clusters that produce poor readouts. The J++ lens also incorporates the improvement introduced by the R-lens (using layerwise relevance propagation when performing backward passes to compute the Jacobians), as well as post-hoc filtering of spurious readout tokens. The result is still a single linear map at each layer, so the J++ lens can be used as a drop-in replacement for the J-lens. Across our evals, the J++ lens more reliably surfaces intermediate latent variables used for the model’s reasoning than the J-lens or the R-lens.

The full post contains more details and experiments. We have also released our code and lenses, along with an interactive demo hosted on Neuronpedia.
