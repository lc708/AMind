# AMind 1.2.1 技能更新

本次将 2026-09-08 单次增量资料落实到技能的检索入口、判断规则和评测案例。完整索引为 64,265 条主张、14,715 个段落；原有 54 条人工 Gold、九个主题论点、五个声部和五项张力保持不变。

## 判断规则

| 场景 | 本次明确的适用条件 |
|---|---|
| 自动化研究 | 分别评估已定义失败的修复、研究方向选择和开放式选题；按实际证据决定各项权限。 |
| 检测与解释工具 | 保留方法、目标行为、任务、基线和分布；局部测试失败不能推出整类方法无效。 |
| 模型升级 | 同时比较能力收益和与实际用途有关的行为退化；代际名称不替代任务评估。 |
| 公开评测比较 | 核对文档版本、模型、产品、测试程序与配置；使用适用的修订结果，同时保留历史证据。 |
| 模型实验 | 区分训练干预、观察结果和未发现的行为；实验模型的结果不能直接归到线上模型。 |

具体来源和 claim ID 见技能的[增量参考](../../../skills/amind/references/increment-2026-09-08.md)。这五项是既有推理框架的应用条件；没有将新增资料全部提升为新的机构立场。

## 验证结果

- 31 项自动测试通过，包括原有检索回归及 7 个新增检索案例，检索案例共 11 个。
- 将 Git 暂存区导出为不含本地采集文件的干净副本后，同样通过 31 项测试。
- 技能结构校验通过；已安装副本在其他工作目录执行 11 个检索案例通过，数据完整性检查通过。
- 两次同一运行环境中的索引重建字节一致；与提交索引的全部逻辑记录也一致，避免把不同 SQLite 或压缩库的文件布局差异误判为证据变化。
- 保留原有 8 个推理评测案例，新增 5 个。案例目录是后续行为评测的输入，不代表本次运行了全部 13 个模型答题案例。

独立试用在中间草稿上完成了研究代理授权、模型替换、奖励投机实验和职业选择四个场景，保存了实际答复、查询和引用链。AI 审查认为三个场景符合核心边界；奖励投机场景正确保留了实验条件，但把同一实验的边界说明标为 `[Strong framework inference]`，标签过强。

1.2.1 已在证据规范中明确：同一实验的两条 claim 不等于跨作品的重复机制；原文直接支持的发现与明确限制使用 `[Public position]`，超出原文的额外解释需跨作品证据或标为 `[Exploratory extrapolation]`。相应条件也加入了推理案例。独立代理在保存四个答复后遇到额度限制，未对这项修正再次盲测；本记录不声称该行为问题已通过独立复测。
