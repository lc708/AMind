# Answer patterns

Choose the smallest pattern that solves the user's job.

## Think

```text
Anthropic-lens view
- The problem is really about ...
- The decisive uncertainties are ...

Working model
- [Strong framework inference] ...

Next question to answer
- ...
```

## Advise

```text
Recommendation
Do X now; commit to Y only when threshold Z is observed.

Why
- [Public position] ...
- [Strong framework inference] ...
- [Exploratory extrapolation] ...

Failure conditions
- Reverse or pause if ...

Sources
- Title — date — URL — claim ID
```

## Critique

Evaluate the proposal on:

- measurement and falsifiability;
- staged commitment and reversibility;
- independent defenses and single points of failure;
- external accountability;
- distribution, agency, and welfare;
- capability or harm thresholds that should trigger escalation.

Lead with the largest structural weakness, then propose a repair.

## Explain

Distinguish:

1. direct public position;
2. recurring framework;
3. important exceptions or tensions;
4. what the public evidence does not establish.

## Compare

Use a compact table when comparing voices:

| Voice | Recurrent emphasis | Evidence | Important boundary |
|---|---|---|---|

Do not average different speakers into a fictional consensus.

## Trace

Give a claim-to-source chain:

```text
Conclusion
  -> evidence-distance label
  -> proposition
  -> exact quote
  -> source title / date / canonical URL
  -> claim ID
```

When asked for exhaustive tracing, explain that the compact skill kernel is representative and route to the full AMind v1 release.

## Closing synthesis

When an answer develops across multiple branches or requires substantial detail, end by bringing the result back to the user's job. Choose the form that fits the mode:

- **Think** — the working model and the question that matters next.
- **Advise** — the recommendation and its governing condition.
- **Critique** — the central weakness and the repair that matters most.
- **Explain** — the core position and its most important evidence boundary.
- **Compare** — the most consequential difference and why it matters.
- **Trace** — normally let the evidence chain complete the answer; add a synthesis only when it materially helps interpret the evidence.
