## October method changes

- URL or bundled-template onboarding produces reviewable configuration files and a dry-run plan; thirteen domain routes select actual packaged template records.
- Staged workflows use the local executable journal: item and aggregate phases, crash recovery, stable operation identities, cumulative budgets and explicit uncovered populations. It is not Claude Dynamic Workflows or a hosted scheduler.
- Native Responses Multi-agent contracts preserve root/child attribution, hosted/unknown items and injection acknowledgements; unsupported compaction/reasoning/tool-limit modes are rejected before calls.
- Cache diagnostics and context-probe coverage distinguish actual observations from missing/inapplicable checks.
- Network scope and update merge/replace semantics must be checked separately in each destination runtime.

Local tests are `scripts/test_amind_behavior_regressions.py` plus the existing application/kernel suites. They use local subprocesses/SQLite and captured or synthetic payloads. Hosted services, model quality, language compilation and account access remain separate evidence.
