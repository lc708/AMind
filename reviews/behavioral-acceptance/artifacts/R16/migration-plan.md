# 执行合同（实现前记录）

范围：任务只提供旧解析器、旧历史策略和两个响应固定数据，没有应用仓库、SDK、锁文件、模型配置或网络权限。实现一个可直接接收 JSON 字典的 Python 标准库适配器及离线入口；不声称已经修改未提供的线上调用点。

| 表面 | 分类 | 目标行为 / 验收 |
| --- | --- | --- |
| 首项文本解析 | 必须改变 | 遍历异构 output；文本投影与完整状态分离；旧式单消息文本保持一致 |
| history 只存文本 | 必须改变 | 选择客户端唯一状态所有者；按顺序保留完整 output、phase、opaque 字段和 call_id |
| commentary / final | 必须改变 | commentary 可展示，但不得直接认定任务完成；工具调用须待结果后续传 |
| incomplete / failed / cancelled | 必须改变 | 保留状态、错误、原因、usage 和原始响应；禁止隐式重试或继续执行工具 |
| 工具结果 | 必须改变 | 对应确切 call_id；支持多个调用；拒绝未知、重复冲突和畸形参数；本地固定 lookup |
| 续传 / 恢复 | 必须改变 | 原样 JSON 快照恢复；配置由调用方提供；拒绝同时传 server state；校验本地 scope |
| 模型、提示词、采样、预算 | 兼容保留 | 请求配置逐字段复制，不选择或替换模型，不自行提高预算 |
| SDK 升级 / 锁文件 | 未提供 | 不杜撰版本或 SDK 方法，不新增依赖 |
| 实际模型质量、延迟、价格、服务接受性 | 未验证 | 零网络、零模型调用；固定测试只能证明结构行为 |
| stream / batch / 服务端 compaction 调用 | 范围外 | 不提供这些入口；已存在的 opaque 项仅原样传递，不生成或解密 |

质量标准：原始任务不变；正常文本等价；完整 output 往返相等；给定不完整响应不得返回成功；调用结果关联正确；入口与恢复路径测试通过。失败后停止且保存诊断，不自动调用模型、重试或提高 token 上限。没有新增延迟目标，运行时间只记录本地检查，不当作模型性能。

回退：原始 task.json 中旧代码保持不变；legacy.py 保存旧策略用于同一固定数据的对照。新增适配器未接入任何生产系统，撤回只需停止使用新入口。旧策略已知会丢失状态，不应作为上线建议。
